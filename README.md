Slot Swapper — MERN Application

A Slot Swapper web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js) that allows users to create work or meeting slots, 
mark them as swappable, and exchange slots with other users through a real-time swap request system using Socket.IO.

Tech Stack

| Layer          | Technology                                                |
| :------------- | :-------------------------------------------------------- |
|   Frontend     | React.js, Tailwind CSS, Zustand (state management), Axios |
|   Backend      | Node.js, Express.js                                       |
|   Database     | MongoDB (Mongoose ORM)                                    |
|   Real-time    | Socket.IO                                                 |
|   Auth         | JWT (JSON Web Token)                                      |
|   Deployment   | Vercel (Backend) + Vercel (Frontend)                      |
